        Horizon · Minecraft на Rust

        Клиент Horizon и основные ресурсы Minecraft 26.3 включены в установщик. Звуки и музыка (~377 МБ) скачиваются при первом запуске Rust; затем доступны без повторной загрузки.

        Экспериментальный клиент для Minecraft 26.3. Нужны Microsoft-аккаунт с Java Edition, horizon-client.exe и подготовленные ресурсы. Java-моды не поддерживаются. Для выбранной сборки создаётся отдельная Rust-копия миров, настроек и ресурс-паков. Java-моды и Java-шейдеры не запускаются; поддерживаются нативные моды в horizon-mods.
