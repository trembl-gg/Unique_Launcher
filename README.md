# UNIQUE LAUNCHER

UNIQUE LAUNCHER - настольный лаунчер для закрытого Minecraft-проекта. Он объединяет авторизацию, подготовку клиентской сборки, профиль игрока и запуск на сервер проекта в одном Electron-приложении.

Проект ориентирован на контролируемую игровую среду: игрок входит под своим ником, настраивает профиль, выбирает ресурсы для клиента и запускает подготовленную Fabric-сборку без ручной возни с файлами.

## Возможности

- вход и регистрация по нику;
- запоминание последней активной сессии;
- профиль игрока с персональными параметрами;
- выбор максимального объёма ОЗУ;
- запуск Fabric-клиента на сервер проекта;
- подготовка локальной Minecraft-директории перед стартом;
- интеграция Discord Activity;
- интеграция Spotify для отображения текущей музыки;
- поддержка пользовательских скинов и плащей в рамках клиентской сборки;
- кастомный интерфейс Electron с собственным управлением окном;
- сборка Windows-установщика через electron-builder.

Некоторые проектные детали, внутренние протоколы и серверная логика намеренно не описаны публично.

## Структура ядра

- `main.js` - основной процесс Electron: настройки, сессии, запуск клиента, системные интеграции.
- `preload.js` - безопасный IPC-мост для renderer-части.
- `renderer/` - интерфейс лаунчера.
- `package.json` - зависимости, скрипты и конфигурация сборки.
- `build/installer.nsh` - минимальная настройка uninstall-поведения Windows-установщика.

Моды, плагины, приватные ассеты, `.env`, логи, готовые сборки и рабочие директории не входят в git-репозиторий.

## Разработка

```powershell
npm install
npm start
```

Проверка JavaScript:

```powershell
npm run check
```

Сборка Windows-установщика:

```powershell
npm run dist
```

## Конфигурация

Чувствительные значения задаются через `.env` или переменные окружения. Файл `.env` не должен попадать в репозиторий.

Основные переменные:

- `PROJECT_SERVER_HOST`
- `PROJECT_SERVER_PORT`
- `UNIQUE_DISCORD_CLIENT_ID`
- `SPOTIFY_CLIENT_ID`
- `SPOTIFY_CLIENT_SECRET`
- `SPOTIFY_REDIRECT_PORT`
- `PROJECT_TPS_URL`

## Релиз

Текущий релиз: `1.0.0`.

Перед публикацией:

1. Проверить `.env` и локальные ассеты.
2. Собрать приватные моды/плагины отдельно.
3. Положить нужные `.jar` в runtime-папки перед упаковкой.
4. Запустить `npm run check`.
5. Запустить `npm run dist`.
