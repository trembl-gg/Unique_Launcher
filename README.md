# UNIQUE LAUNCHER

Текущий релиз **1.0.3**: [список изменений](CHANGELOG.md).

UNIQUE LAUNCHER — настольный Minecraft-лаунчер для Windows с нативной оболочкой на Rust и WebView2. Он объединяет Microsoft- и офлайн-вход, подготовку локальных сборок, Modrinth, профиль игрока и запуск Minecraft.

Перенос выполняется по слоям: окно, IPC, системная информация, выбор и перетаскивание файлов, аудиометр, режим стримера и значки Minecraft реализованы на Rust. Игровой backend (`main.js`, `lib/`) пока работает в Node.js через stdin/stdout. Интерфейс остаётся HTML/CSS/JavaScript. Это промежуточная версия миграции, не полностью Rust backend. Подробности: [docs/rust-migration.md](docs/rust-migration.md).

Проект ориентирован на контролируемую игровую среду: игрок входит под своим ником, настраивает профиль, выбирает ресурсы для клиента и запускает подготовленную Fabric-сборку без ручной возни с файлами.

## Возможности

- вход через Microsoft и офлайн-профиль;
- запоминание последней активной сессии;
- профиль игрока с персональными параметрами;
- выбор максимального объёма ОЗУ;
- запуск Fabric, Forge, NeoForge, Quilt и vanilla-сборок;
- отдельный запуск Minecraft на Rust через Horizon: клиент и основные ресурсы Minecraft 26.3 включены в компактный установщик, звуки и музыка (~377 МБ) скачиваются при первом запуске и сохраняются; требуется Microsoft-аккаунт с Java Edition;
- подготовка локальной Minecraft-директории перед стартом;
- интеграция Discord Activity;
- интеграция Spotify для отображения текущей музыки;
- автоматическая проверка GitHub latest при входе и каждые 30 минут, список изменений новой версии и переход к скачиванию; описание текущего релиза доступно без сети в диагностике;
- поддержка пользовательских скинов и плащей в рамках клиентской сборки;
- интерфейс на системном Microsoft Edge WebView2 с собственным управлением окном;
- автономная Windows-сборка без Electron runtime.

Некоторые проектные детали, внутренние протоколы и серверная логика намеренно не описаны публично.

## Структура ядра

- `main.js` — локальный Node backend: настройки, сессии, запуск клиента и системные интеграции.
- `webview2/` — WinForms-хост WebView2, локальный IPC-мост и сценарий упаковки.
- `renderer/webview2-bridge.js` — безопасный мост между интерфейсом и локальным backend.
- `renderer/` - интерфейс лаунчера.
- `package.json` - зависимости, скрипты и конфигурация сборки.
- `build/installer.nsh` - минимальная настройка uninstall-поведения Windows-установщика.

## Разработка

```powershell
npm install
npm start
```

Проверка JavaScript:

```powershell
npm run check
```

Сборка автономного Windows-лаунчера:

```powershell
npm run dist
```
