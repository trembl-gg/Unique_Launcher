# UNIQUE Launcher 1.3.0

- Единые страницы завершения Microsoft/Spotify OAuth: адаптивный интерфейс, успех/отмена/ошибка, RU/EN/ES, кнопка закрытия вкладки. Страницы не показывают коды и токены, не кешируются и не загружают внешние ресурсы.
- На фоне процедурная фиолетовая туманность и 1800–6500 движущихся и мерцающих звёзд в зависимости от размера окна. Световые облака плывут по фону, периодически появляются падающие звёзды. Текстура кешируется, анимация ограничена 30 кадрами/с и приостанавливается в скрытом окне; уменьшенное движение отключает мерцание и движение. В светлой теме звёзды тёмные.
- Видимый журнал показывает понятные сообщения с уровнями INFO, ERROR, WARN и DEBUG. Уровни можно фильтровать; отладка скрыта по умолчанию. Служебные lifecycle JSON и стеки ошибок подготовки остаются только в диагностическом файле с удалением секретов. Причина, способ остановки и код выхода отображаются кратко; подробные отчёты игры сохраняются для диагностики.
- Исправлено открытие папок из главного меню: «Файлы» открывает выбранную сборку, «Логи» — папку журналов. Ошибки открытия показываются в журнале.
- Окно Minecraft Rust получает значок UNIQUE; Java сохраняет собственный игровой значок. Оболочка получает PID и тип запущенного клиента, чтобы менять значок только у его окон.
- Карточка выбранной сборки получила акцентный градиент и теги загрузчика/версии. Действия отделены от карточки отступом, уровни журнала оформлены подсвечиваемыми переключателями. Нижняя панель запуска закреплена без отступа от нижнего края окна.
- Убрана дублирующая верхняя полоса; профиль и выход перенесены в заголовок окна с сохранением выдвижения и красного наведения для выхода. Выделение сборки в левой панели не обрезается. Добавлены SVG-иконки копирования, действий со сборкой, добавления аккаунта, поиска, импорта и выбора папок.
- Пользовательские картинки сборок отображаются без цветной подложки в боковой панели и библиотеке: прозрачность PNG сохранена, активная сборка выделяется рамкой. Буквенные заглушки сохраняют цветной фон.
- `.gitignore` исключает установщики, зависимости, кеши сборки, игровые данные, логи, дампы, временные загрузки и локальную конфигурацию Spotify.
- Исправлены переводы `java из PATH`, динамических версий и результатов Modrinth, сообщений Horizon и подготовки ресурсов. Видимые основные разделы проверены в EN/ES; названия пользовательских сборок, технические логи и название языка «Русский» не переводятся.
- Discord Activity всегда содержит кнопку скачивания последнего релиза: «Скачать лаунчер», “Download launcher” или “Descargar launcher”. URL: `https://github.com/trembl-gg/Unique_Launcher/releases/latest`. При смене языка активность обновляется; вторая кнопка сохраняет соцсети профиля.
- В **Настройки → Игра → Настройки лаунчера** добавлен выключенный по умолчанию переключатель снапшотов. Он показывает современные тестовые версии официального манифеста при создании сборки. Выключение не блокирует ранее созданные сборки. Для тестовых версий рекомендуется Vanilla; доступность загрузчиков определяется их авторами.
- Java выбирается с учётом `javaVersion.majorVersion` из метаданных Minecraft. Если подходящая версия отсутствует, показывается требование и предлагается установка соответствующей Java.
- Контекстное меню отключено во всём интерфейсе, кроме журнала запуска: там остаётся копирование текста. Правило также действует на поля ввода; в старой C#-оболочке включена возможность показать меню там, где его разрешает интерфейс.
- Удалены 63 устаревших артефакта/папки: 7893888346 байт (7,35 ГиБ). Это старые установщики, копии дистрибутива, исследовательские загрузки Horizon и отладочный кеш. Исходники, инструменты сборки, пользовательские данные и резервные настройки сохранены. Исходный HTML-макет перенесён в `docs/reference/launcher-original.html`, JVM-отчёт — в игнорируемую папку `logs`.

Проверены общий `npm test`, `npm run test:release`, синтаксис, браузерный интерфейс с настоящим backend, переключение снапшотов и языков, поведение ПКМ, адаптивные callback-страницы и их CSP. Установка настоящего `26.4-snapshot-6` через `LoaderService.ensureVanillaVersion` завершилась успешно: JAR 42156998 байт, размер и SHA-1 совпали с официальными метаданными; требование — Java 25.

Полный игровой сеанс нового снапшота с Microsoft-аккаунтом и отображение кнопки с другого аккаунта Discord вручную не проверялись. Публикация релиза и push не входят в локальный коммит.
