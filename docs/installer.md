# Установщик UNIQUE LAUNCHER

Сборка: `npm run dist:installer` (также `npm run dist`). Требуются Windows, Rust stable, MSVC Build Tools либо MinGW-w64, Node.js/npm и NSIS 3. При необходимости задайте `UNIQUE_NSIS_PATH` — полный путь к makensis.exe.

Результат: `dist/UNIQUE-Launcher-Setup-<версия>.exe`. Приложение Windows x64 содержит нативный Rust EXE и Node.js для ещё не перенесённого backend; .NET и Electron не упаковываются. Для значков приложения, установщика и удаления используется файл `unique иконка.ico` из корня проекта.

Ярлыки используют ресурс иконки EXE с индексом 0, а не путь к ICO с кириллицей. Прозрачный исходник — `unique.png`; игровой вариант с блоком — `game.png` / `game.ico`. В публикации иконка лаунчера дополнительно лежит как `launcher.ico`. После обновления установщик пересоздаёт ярлыки и уведомляет оболочку Windows об изменении.

Пересоздание многоразмерного ICO: `./scripts/convert-icon.ps1 -Source unique.png -Destination 'unique иконка.ico'` и аналогично для `game.png`. Проверка: `node scripts/check-icons.js`.

Значок Minecraft назначается окну Java-процесса из события `launch-started` через WM_SETICON; другие Java-процессы и файлы установленной Java не изменяются. Обработчик завершает работу при выходе процесса или закрытии лаунчера. Полноэкранные переходы отслеживаются с интервалом 2 секунды.

Установка выполняется для текущего пользователя, по умолчанию в `%LOCALAPPDATA%\Programs\UNIQUE LAUNCHER`. Создаются ярлыки и запись удаления в Windows. При отсутствии WebView2 предлагается установить официальный Microsoft Runtime; для этого нужен интернет. Подпись загрузчика Microsoft проверяется при сборке. Сам установщик не подписан сертификатом издателя, поэтому Windows может показать предупреждение SmartScreen.

Удаление убирает только перечисленные при сборке файлы программы. Пользовательские аккаунты, настройки и игровые данные в AppData сохраняются. Перед обновлением или удалением закройте лаунчер.

Rust-оболочка управляет окном через Tao/Wry. Старый C#-путь доступен отдельно через `npm run start:legacy` и `npm run dist:webview2`.

Скрипт упаковывает только production-зависимости, отклоняет обнаруженные `.env` и файлы приватных ключей и удаляет свою временную staging-папку после сборки. Старые релизы автоматически не удаляются.
