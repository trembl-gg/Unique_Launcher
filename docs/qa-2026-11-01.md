# Проверка лаунчера — 1 ноября 2026

## Исправлено

- Заголовок установленного содержимого обновляется и при возврате с миров/текстур к модам.
- Кнопка обновления и повторное открытие раздела обновляют текущий тип содержимого.
- Поиск не применяет устаревший ответ после нового запроса, смены типа содержимого или сборки.
- Ошибка транспорта при поиске отображается в интерфейсе.
- Установка текстур/шейдеров показывает результат в том блоке, где пользователь нажал кнопку; после ошибки кнопка разблокируется, после успеха список обновляется.
- Кнопки установки правильно называют тип содержимого.
- Поиск modpack больше не отклоняет Vanilla до обращения к backend: backend уже умеет искать без фильтра загрузчика.
- «Открыть папку» использует выбранную сборку и тип содержимого. Backend поддерживает mods/resourcepack/shader/worlds и прежние plural-алиасы.
- Заголовки страницы и поиска соответствуют выбранному содержимому; проверка обновлений модов скрыта для остальных типов.

## Интерфейс

Каталог Modrinth переведён в одноколоночный список с читаемыми описаниями. Упрощены фоны карточек и выделение выбранной сборки, добавлен видимый клавиатурный фокус. Это ограниченное приближение сценариев каталога, а не полная копия Modrinth App.

## Проверки

- `npm run check`: синтаксис 43 JS-файлов.
- `npm test`: все существующие проверки и новый `scripts/check-catalog-ui.js` проходят.
- `scripts/check-launcher-ui.js`: настоящий HTML и локальный stdio backend, временный отдельный профиль; внешние HTTP-запросы заблокированы.
- Через реальные кнопки: офлайн-вход, главная/библиотека/профиль/настройки, все пять вкладок настроек, создание сборки, переход в миры, возврат к модам, текстуры, обновление списка, редактор, сохранение имени и избранного, поиск с результатом и без, повторное открытие редактора.
- Проверена ширина 960 и 1280: горизонтального переполнения документа нет. Скриншоты находятся в `.tools/qa-*.png`.
- Для запуска браузерной проверки нужен Playwright: задайте `UNIQUE_PLAYWRIGHT_MODULE` путём к установленному пакету. Используется установленный Brave.

## Ограничения

Установленные окна обоих приложений обнаружены. Главный экран UNIQUE прочитан через accessibility. Захват окон возвращал `window capture timed out` / `FrameArrived timed out`, ввод — `coordinate input geometry is unavailable`. Поэтому полный ручной проход установленных приложений и визуальное сравнение с Modrinth не выполнены.

Не проверены реальный запуск Minecraft, успешная Microsoft-авторизация, Spotify/Discord, сетевой каталог, скачивание/установка модов и сборок, системные диалоги выбора файлов. Изменения не доказывают отсутствие других ошибок.

Обновлены исходники, три runtime-файла в `dist/rust` и установленном UNIQUE LAUNCHER. Хеши установленных файлов сверены. Предыдущие установленные файлы сохранены в `.tools/installed-before-qa`. Текущее запущенное приложение нужно перезапустить для применения backend-изменений; аккаунты и игровые файлы не изменялись.
