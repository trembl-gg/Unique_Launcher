# Игра, журналы и streamer mode

- Перед запуском: «Остановить запуск». После создания процесса Minecraft: «Остановить». После выхода: «Запустить».
- Состояние берётся из процесса, а не только из событий интерфейса. Пока запуск активен, есть резервная проверка раз в 2 секунды. Событийный поток переподключается с последним ID; хранится ограниченная очередь для повторной доставки.
- В `%APPDATA%\minecraft-launcher\logs` сохраняются stdout/stderr и диагностика запуска (`minecraft-*.log`), а также ошибки Windows-хоста (`native-host.log`). Кнопка открытия логов открывает эту папку.
- С 1.3.0 записи `[lifecycle]` фиксируют этап подготовки, запрос остановки пользователем, метод отмены/закрытия, PID, код и сигнал выхода. Отмена до создания процесса, штатное закрытие через WM_CLOSE, ошибка запуска и неизвестная причина аварийного выхода различаются. Поле `stack` очищается от секретов вместе с остальными логами.
- После выхода собираются свежие `logs/latest.log`, `crash-reports/crash-*.txt`, `hs_err_pid*.log` из папки запущенной сборки. Для каждого файла берётся хвост до 64 КиБ, для запуска — не больше 16 МиБ. Старые crash-report не выдаются за новый краш. Обычная остановка пользователем не вызывает вывод crash-report в интерфейсе. Логи хранятся локально; автоматической отправки нет.
- Значок игры назначается только запущенному Java-процессу. Игра получает отдельную группу панели задач `UNIQUE.Minecraft`; её окна проверяются повторно при переключении полноэкранного режима. Не требуется менять java.exe или ставить мод.

Streamer mode находится в «Настройки → Экспериментальные функции». Используется [SetWindowDisplayAffinity / WDA_EXCLUDEFROMCAPTURE](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowdisplayaffinity), Windows 10 2004+ / Windows 11. Локальное предпочтение применяется при создании окна, до показа интерфейса. Режим защищает только окно лаунчера, не игру, браузер авторизации и внешние диалоги. Это не гарантия против любого способа захвата: обязательно проверить предпросмотр конкретной программы трансляции.

Проверки: `npm test`, `dotnet build webview2/UniqueLauncher.WebView2.csproj -c Release`, `dotnet run --project scripts/native-smoke/NativeSmoke.csproj -- game.ico`. Последняя проверка создаёт собственные окна вне экрана и проверяет назначение иконки другому процессу и включение/выключение capture-affinity; она не запускает Minecraft и не проверяет OBS/Discord.
