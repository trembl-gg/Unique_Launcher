# Иконки UNIQUE

Использованы встроенный imagegen и исходный `unique иконка.png`. Выбраны версии, сохраняющие исходный силуэт; экспериментальные варианты не включены в приложение.

Итоговые запросы:

- Лаунчер: сохранить фиолетовый символ UNIQUE, удалить чёрный фон и фон глаз/между рогами, прозрачный PNG, без дополнительных элементов.
- Minecraft: тот же символ на прозрачном фоне, небольшой изометрический блок травы справа снизу для отличия от лаунчера, без текста и фонового квадрата.

Активные файлы: `unique.png`, `unique иконка.ico`, `game.png`, `game.ico`. Скрипт `scripts/convert-icon.ps1` только переводит PNG в многоразмерный 32-битный ICO с сохранением альфа-канала. Исходный PNG с чёрным фоном оставлен как оригинал.

Назначение значка окну игры использует [WM_SETICON](https://learn.microsoft.com/en-us/windows/win32/winmsg/wm-seticon). Файлы Java не модифицируются.
