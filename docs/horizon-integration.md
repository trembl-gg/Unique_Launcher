# Rust-версия Minecraft в UNIQUE

В сборке 1.2.8 **Играть (RUST)** доступна на главной рядом с обычным запуском по умолчанию. Её можно отключить через **Настройки → Экспериментальные → RUST-версия Minecraft · Horizon**. Переключатель сохраняется для профиля; ранее выбранное отключение сохраняется. При работающей игре Rust-кнопка недоступна; обычная кнопка позволяет остановить игру.

Запускается непосредственно `horizon-client.exe`, не `horizon-launcher.exe`. Обновлённый `C:\horizon-launcher.exe` использован для определения установленной игровой версии. Её файлы (Nightly 2026-10-31 · d91cab6) скопированы в рабочую установку UNIQUE и ресурсы подготовлены заново. Сам менеджер Horizon для игры не запускается.

## Сборки

**Играть (RUST)** использует выбранную сборку и Microsoft-аккаунт с Minecraft Java Edition. Каждой паре профиль/сборка соответствует отдельная папка `game-data/horizon/<хеш профиля>/<id сборки>` относительно настроенного игрового хранилища.

- Миры, options.txt и servers.dat копируются из Java-сборки при первом импорте. Прогресс Rust не перезаписывает исходные Java-миры и не сливается обратно. Удалённые после импорта Rust-миры автоматически не возвращаются.
- Активные ресурс-паки и содержимое `horizon-mods` синхронизируются. Удаляются только неизменённые файлы, ранее скопированные UNIQUE; изменения пользователя внутри Rust-копии защищены от перезаписи. Отключённое содержимое `.disabled` не переносится.
- Java `.jar`-моды и Java-шейдеры не исполняются. Количество пропущенных Java-модов сообщается при запуске. Автоматическое портирование Java-кода не реализовано; сборки с такими модами не сохраняют всю свою функциональность.
- Horizon запускает собственную версию Minecraft (здесь 26.3), а не Java-загрузчик сборки. Старые миры обновляются только в отдельной Rust-копии. Совместимость конкретного ресурс-пака/нативного мода остаётся ограничением Horizon.
- Символические ссылки в переносимом содержимом отклоняются. Игровые файлы Java-сборки не изменяются. Rust-копии остаются на диске при удалении исходной Java-сборки.

## Установка

Начиная с 1.2.9 установщик компактный: аудиофайлы из `assets/minecraft/sounds` не включаются в EXE. При первом Rust-запуске они скачиваются с официального `resources.download.minecraft.net` по встроенному индексу Minecraft: 4961 файл, 376664246 байт (около 377 МБ). Лаунчер проверяет размер и SHA-1 каждого файла; корректные файлы повторно не скачиваются, прерванная загрузка продолжается при следующем запуске. В интерфейсе показывается процент подготовки. Для этого запуска требуется интернет.

Полный комплект собирается в `<игровое хранилище>/horizon/resources/<хеш основных ресурсов>` и используется всеми Rust-сборками. Это позволяет устанавливать лаунчер в папку без прав на запись. Основные ресурсы копируются в кеш один раз; аудио не хранится повторно в папке установки. Пользовательские внешние полные ресурсы Horizon продолжают работать напрямую. Размер установленной игры после скачивания аудио не уменьшается.

Установщик 1.2.8 включает `horizon/horizon-client.exe`, лицензию Horizon и подготовленные ресурсы `horizon/resources/26.3`. Пути определяются относительно папки установленного UNIQUE; отдельная установка менеджера Horizon для игры не требуется. Сборка берёт подготовленный клиент из локальной установки Horizon. Minecraft-сессии, игровые миры, пользовательские настройки и логи подготовки в установщик не копируются. Сохранённые пути к другой доступной установке продолжают работать; отсутствующие пути заменяются встроенными. В режиме разработки также распознаётся локальная установка менеджера Horizon.

Для сборки используется подготовленная локальная версия `nightly-2026-10-31-d91cab6` из `%APPDATA%/horizon-launcher/versions`. Для установленного UNIQUE приоритет имеет встроенный клиент; вручную выбранные рабочие пути сохраняются. Пути можно изменить в разделе Horizon на вкладке «Экспериментальные».

## Проверка

Сборка 1.2.9: компактный `dist/rust-compact` проверен без внешней установки Horizon. Впервые скачаны все 4961 аудиофайл с официального CDN, проверены размер и SHA-1. Повторная подготовка прошла с принудительно запрещённой загрузкой. Настоящий встроенный клиент с восстановленными ресурсами отработал 60 кадров меню: код 0, `error: null`; отчёт `.tools/horizon-compact-smoke/report.json`. Прошли общий `npm test`, браузерный UI-тест, проверка синтаксиса и backend stdio из компактного дистрибутива. Отдельно проверены повреждённый звук, повтор после ошибки сети, отмена и отклонение пути за пределы ресурсов. Полный игровой сеанс с Microsoft-авторизацией не проверялся.

Установщик 1.2.9: 67898918 байт против 419556307 байт у 1.2.8 — уменьшение в 6,18 раза (83,82%). SHA-256: `84703f2a2e902451295a004bc445e95eff202f3c0e06d372c9d17975eb520f0a`.

Сборка 1.2.8: встроенный `dist/rust/horizon/horizon-client.exe` проверен с ресурсами из `dist/rust/horizon/resources/26.3` без обращения к внешней установке Horizon. Launch API 0.1.0; реальный запуск меню завершился после 60 кадров с кодом 0 и `error: null`. Отчёт: `.tools/horizon-bundle-1.2.8-smoke/report.json`. Также прошли backend stdio из собранного дистрибутива, общий `npm test` и браузерный тест кнопки на ширине 960/1280. Полный игровой сеанс с Microsoft-авторизацией в этой проверке не выполнялся.
