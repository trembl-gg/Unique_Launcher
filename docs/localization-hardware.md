# Язык, монитор и память

- RU/EN/ES сохраняется как настройка устройства (`uiLanguage`), включая экран входа и смену аккаунта. Более старый ответ сохранения не перезаписывает новый выбор.
- Локализатор хранит исходный текст и узнаёт копии уже переведённых подписей в выпадающих списках. Добавлены переводы экрана входа, настроек, сборок, профиля и стандартных статусов. Названия пользовательских сборок, аккаунтов и логи не переводятся.
- Windows-хост читает текущий режим именно монитора окна через `Screen.FromHandle` и `EnumDisplaySettingsW`. Это частота режима рабочего стола, не мгновенная частота VRR. Если драйвер не сообщает частоту, интерфейс показывает «—», а не выдуманные 60 Гц. Перед запуском игры частота считывается повторно и передаётся в ограничение FPS.
- `GetPhysicallyInstalledSystemMemory` определяет установленную RAM, `GlobalMemoryStatusEx` — доступную системе и свободную сейчас память. Эти значения не смешиваются. Основная подпись показывает установленный объём, подсказка — доступный Windows и свободный объём.
- Ползунок памяти ограничен используемой Windows RAM за вычетом резерва 1–2 ГБ, с шагом 256 МБ. То же ограничение проверяется в backend при сохранении и загрузке настроек. Старого фиксированного предела 16 ГБ при полученных данных системы нет.
- В настройках больше нет меню версии Minecraft, проекта и Fabric Loader. Внутренние поля совместимости скрыты, выбор версии остаётся в создании сборки. Java вынесена отдельно; удалены карточки готовности удалённого API.

Проверки: `npm test`, `dotnet run --project scripts/native-smoke/NativeSmoke.csproj -- game.ico`.

На тестовом компьютере Windows сообщил 180 Гц, 32768 МиБ установленной и 32690 МиБ используемой RAM. Переключение между разными физическими мониторами вручную не проверялось.
